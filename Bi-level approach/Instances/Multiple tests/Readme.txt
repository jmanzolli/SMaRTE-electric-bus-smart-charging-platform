This file contains information about the testbed for the MILBLO problems.

===========================================================================================================================================================================

The instances are defined as follows:

Instance input.xlsx Ð Default scenario.

Instances 01_xx.xlsx Ð Refers to the number of buses and routes in the referred instance (xx is the number of vehicles/routes).

Instances 02_xx.xlsx Ð Refers to the number of periods in the referred instance (xx is the number of periods).

Instances 03_xx.xlsx Ð Refers to different settings of max and lower values of allowed energy prices.

Instances 04_xx.xlsx Ð Refers to different charging power of the chargers (xx is the nominal power)

Instances 05_xx.xlsx Ð Refers to different energy consumptions of the buses (xx is the energy consumption)
